# Signal Shelf

Персональная полка материалов (статьи, ссылки, заметки) на **React 19 + TypeScript**.  
Учебный pet-проект в формате микрошагов — см. [LEARNING.md](./LEARNING.md).

## Stack

- Vite + React + TypeScript
- React Router
- TanStack Query (с шага 9)
- CSS (design tokens) — визуал собран отдельно от учебной логики

## Dev

```bash
npm install
npm run dev
```

## Статус

Каркас и вёрстка готовы. Логика заполняется по шагам LEARNING.
